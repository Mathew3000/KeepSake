# Emergency recovery guide (draft)

1. Find the sealed master-password envelope and follow the personal emergency letter.
2. Connect the KeepSake device to a computer **only after USB mass storage has been implemented and hardware validated**. Until then, remove the microSD card and use a trusted SD reader.
3. Choose the most recent verified backup; do not assume the newest is readable until tested.
4. Open the KeePass .kdbx database with KeePass/KeePassXC. A key file, if configured, is separately required.
5. Read the infrastructure instructions stored in an encrypted bundle. **Do not store private infrastructure documentation in plaintext on removable media.**
6. In case of device failure, use the independent offline reference backup.

Periodically perform a full recovery rehearsal with the intended nontechnical user. Document how to access the files without the original server.
